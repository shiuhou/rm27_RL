# SE3 radio starter

An independent reproduction package for connecting a Bluetooth game controller
through pygame to an SE3 MuJoCo controller. It is a research/input-layer
package, separate from the RM27 root flight stack and real flight control.

Its tests cover interface behavior and mapping logic. They do not establish
MuJoCo dynamics, Bluetooth hardware, or real-aircraft performance. See
`README_zh-TW.md` for setup and usage.
