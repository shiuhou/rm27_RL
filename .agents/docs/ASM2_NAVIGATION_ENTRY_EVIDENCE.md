## 结论与可交付级别

**现有证据能提供完整成功状态样本，不能提供可直接执行的导航进场包线。** 五组 Fixed A 起始状态均有自主首次接触成功；部分有极小的耦合位置／速度扰动成功。它们已经处于回正运动中，带切向速度、角速度和特定电机状态，不能把位置与速度的最小／最大值拼成可任意组合的范围。

目前交付给导航侧的级别为 `REFERENCE_ONLY`：坐标定义、五个关联状态样本、已测试方向和失效证据。部署进场设定值、允许误差、接管许可阈值及退出阈值仍为 `UNKNOWN / NOT_RELEASED`。没有声称已验证触板后恢复或官方撞击计分。

## 坐标与高度

本轮核对 `contact_task.load_contact_spec`：仿真平移后原点为装甲板中心，世界 Z 为重力反方向。保存的目标旋转矩阵列为沿坡、横向、朝飞机侧法线：

```text
沿坡 e_s = [ 0.8870284342, 0, 0.4617148005]
横向 e_a = [ 0,            1, 0           ]
法向 e_n = [-0.4617148005, 0, 0.8870284342]
```

位置 `p = s*e_s + a*e_a + d*e_n`，机体 COM 距离板面所在平面的法向距离为 `d`。相对板中心重力高度为 `h = 0.4617148005*s + 0.8870284342*d`。水平距离为 `sqrt(p_x²+p_y²)`。接近速度定义为 `-v_n`，正数表示接近。距离均针对 COM，不是机体最小净空。

历史场地 CAD 板中心为 `[11.4561, 0, 1.079] m`，但这是模型坐标，不能直接用作现场离地高度。实际导航需要板中心的现场高度、绿灯至板中心／法线标定，以及一致的机体定位参考点。这里的高度不是“高于绿灯多少”；本轮检查的配置和接口文档未提供可用于此转换的绿灯注册数据。

## 已测试误差与缺口

R5/R5.1 扰动为位置 ±0.5 mm 与同方向速度 ±5 mm/s **同时改变**，保持姿态、角速度、电机实际推力和 held targets 不变。

| 样本 | 沿坡负／正 | 横向负／正 | 可说的结论 |
|---|---|---|---|
| center:725 | 通过／通过 | 通过／通过 | 两个方向存在成功端点 |
| fast:816 | 通过／通过 | 失败／通过 | 负横向出现 forbidden first manifold |
| near_slow:702 | 通过／通过 | 通过／通过 | 两个方向存在成功端点 |
| stationary_0:330 | 未测试 | 通过／通过 | 只有横向成对端点证据 |
| stationary_2:346 | 通过／通过 | 通过／通过 | 两个方向存在成功端点 |

不能宣称 ±0.5 mm 为连续容差，更不能外推到厘米级导航误差。没有独立位置、独立速度、法向距离／速度、姿态、时延、电机误差的联合包线。R5 的 near_slow:702 通过、706 失败、707 已存档通过，说明“更近、更慢、更对齐一定更容易”不成立。fast 的失败包含零加载的禁止机体接触点，保持原 scorer 判定，不以加载与否改写结果。

## 如何收敛成可给导航的数值规范

1. **接口注册。** 导航侧提供绿灯与板面的实际几何关系、定位参考点、可实现的接近速度／姿态范围、估计误差和时延。本研究侧负责将其映射到板中心坐标，给出位置、高度和速度要求；不要求导航复现 witness。
2. **候选选择。** 用上述完整成功状态及失败邻居约束候选，把导航真正能持续接近产生的低角速度状态与当前带旋转样本分开。保留所有状态耦合，不能只替换速度或姿态后沿用成功标签。
3. **唯一下一项建议，尚未执行：冻结一项“导航可达进场状态的 Fixed A 接管验证”。** 先得到导航可达性与误差资料，再预登记少量成组的位置、高度、速度及完整执行器状态，运行 frozen Fixed A；另验控制交接延迟和能否安全退出。预算与 manifest 需另行确定和授权，不自动新增 rollout，不训练。若普通导航状态无法被当前策略接住，明确记录控制能力缺口，不强迫导航制造研究用的极窄旋转状态。
4. **分级发布。** 首次接触验证通过后，只发布带来源和误差范围的“接触候选进场规范”；完整触板后恢复与退出能力另行通过，才发布完整任务接管许可。每个导航参数必须绑定对应姿态、速度、执行器条件与估计质量，不能发布无条件的单个距离阈值。

当前尚不能诚实地指定“飞到某高度、距离、速度即可接管”。可以立即交付上表用于双方接口讨论，不能把它加载成导航执行指令。
