# Legacy SITL mission scripts

These scripts are historical, direct `pymavlink` mission runners moved from
the M600 lab workspace. They document earlier takeoff, waypoint and return
experiments; they are not part of the current mission coordinator.

Use `rm27.autopilot` and `rm27.experiments` for current, tested entry points.
Any result produced by these scripts must retain its original vehicle, frame,
parameter and firmware context.
