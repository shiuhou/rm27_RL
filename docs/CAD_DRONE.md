映射 `(X,Y,Z) → (-X,-Z,-Y)`，除以 1000 轉為米。
先前 v2 的上下方向錯誤；v3 已繞原模型局部 Y 軸旋轉 180°，保留相機側方向，
並重新以正確底面對齊停機位。這是旋轉，不是鏡像。
CAD 原點偏置已移除；新模型原點位於外包絡底部中心。
相機側看起來朝 CAD -Z，即目前模型 +Y；這是幾何判讀，
尚不能用來設定 ArduPilot 的機頭軸或感測器旋轉參數。

## 運作原理與結構理解

這是一台反槳、電機下置的四旋翼，旋翼單元位於機架下側。
「反槳」不代表總推力向下，飛行時仍需要向上的總升力。
四組旋翼共同提供升力，左右／前後推力差產生滾轉與俯仰；
相反旋向組的反扭矩差控制偏航。實際旋向、馬達編號及接線不能從此 STEP 確認。
CAD 中的圓盤較像旋翼掃掠包絡示意，並非已確認的真實槳型。

上下框板由立柱連成籠狀結構，旋翼與中央電子設備位於框架內。
推測設計意圖是讓外框先接觸外物並保護旋翼；碰撞載荷可能由框板經立柱傳遞。
材料、緊固件、柔性與吸能特性未知，因此不能據此斷言耐撞或撞擊後可正常返航。
周邊仍有開口，CAD 外觀也不能證明完全防護或規則合規。

中央板件提供電子設備的堆疊空間；前端支架固定相機，適合研究前視辨識。
既有使用者硬件紀錄為 1103 9600KV、2 吋槳、約 180 g、MicoAir 飛控、
MTF-02P、M3C + OS04A10；CAD 封裝和零件名稱不能證明每項實際安裝型號。
電池位置與規格、實際重心、重量分配、推力和慣量仍待確認。

## 放入機庫的結果

單台 `cad_drone_1` 放在 `slot_1`，其他三格空置。
停機位寬度為 142.5 mm，因此水平每側間隙約 **14.25 mm**。
底面與停機位底面對齊，機身高 41.916 mm，超出 40 mm 槽深約 **1.916 mm**。
目前機庫是開頂槽，這是靜態外包絡適配，不代表有蓋機庫的關閉間隙或降落容錯。

MJCF 保留全部 393 個實體的三角化外觀，按四組打包，顯示色是示意色，
不是原 CAD 材料。三角化線性設定 0.08 mm、角度設定 0.2 rad。
`drone.xml` 可獨立載入；`scene.xml` 包含背景、機庫、基地與唯一一台飛機。

飛機目前是**固定、無動力、無碰撞的 CAD 外觀模型**，沒有把籠狀機架
粗暴填成凸包，也沒有套用未校準的質量或飛控參數。
機庫與場景原有碰撞保留。這份輸出用來查看結構與安裝位置，不能直接跑飛行指令。

## 指令

```bash
python -m rm27 build-cad-drone --output artifacts/my-cad-drone
python -m rm27 view artifacts/my-cad-drone/scene.xml
python -m rm27 view artifacts/my-cad-drone/drone.xml
```

使用新的輸出目錄；來源和原有獨立場景不會被覆寫。
`summary.json` 記錄原始檔案雜湊、每個實體的 CAD 範圍與三角面數、
模型尺寸、機庫間隙及配置驗證結果。
