不拉取未完成的研究、不修改原來源記錄，避免兩邊平行改動感知實作。

## 本次需要完成

1. 固定 PX4 v1.17.0，正確處理感測、電機、座標、單位、時間、控制
   模式、推力／角速度及 EKF2 融合接口。基本原理錯誤需要修正。
2. 用目前仿真圖像與 IMU，經定位／目標觀測及 PX4 控制，走完
   起飛、觀測、接近／接觸、恢復、重獲機庫、指定槽位降落停槳。
   控制輸入和獨立真值評分保持可追溯；不要求固定毫米／厘米級精度。
3. 提供可重現的場景建置、啟動、觀看、日誌及回放入口。現有完整
   飛行證據已足以證明鏈路可運行；只有改動影響接口或整體行為時，
   才追加相應小規模檢查，不以重複次數作為完成工作的主要手段。
4. 研究入口有 PX4 適配，或明確說明為直接驅動仿真的獨立研究及
   其復用方式。Teacher／Student 的策略性能是後續研究問題；接口
   正確和策略仍待調整可以同時成立。
5. 清楚列出可替換的機體、相機、感測與延遲假設；保留來源時間、
   坐標／外參、尺度、品質、定位失效／epoch及正常降落語義。提供
   接真機時所需資料與接口說明，不要求本輪完成全部實機代碼或標定。

已有成功試跑不能證明所有原理都正確。錯誤坐標、電機順序、推力
單位、時間倒退、把舊圖重標成新圖、定位換原點後沿用舊註冊、無效
估計仍被當作有效輸入等，仍屬遷移需要處理的問題。驗證以具體風險
和受影響接口為限。

## 已觀察問題的含義

| 問題 | 現有證據能說明甚麼 | 現階段處理 |
| --- | --- | --- |
| 圖像對準略超過3 mm而拒絕LAND | 超過原型的嚴格准入門檻，不能據此判定PX4錯誤 | 保留原結果；不反覆追毫米精度 |
| 已完成任務但yaw略低於42°審核下界 | 超出特定幾何證明域；不等於模式／控制接口失效 | 視為暫定幾何研究限制，不再擴域大量計算 |
| 回庫失聯後碰隔板 | PX4確實LAND及停槳；估計漂移與狹小間隙共同影響落位 | 記錄限制，檢查是否有接口原理錯誤；機體未定型時不以反覆無碰撞批次阻擋遷移 |
| 接地後估計速度仍有漂移 | 近地輔助失效及落地確認邏輯的接口問題，已有修正開發證據 | 整理已驗證的遙測／range／停槳確認，保留模型限制 |
| 舊圖時間或定位epoch被錯用 | 輸入資料語義錯誤，影響未來實機接口 | 保留修正與針對性檢查，不把失效資料冒充有效輸入 |
| native VIO在噪聲實驗中退出、激進策略碰撞／恢復失敗 | 感知數值穩定性或策略／模型問題；尚未證明是PX4核心問題 | 記錄失效和接口處理；噪聲可靠性與策略性能另作研究，不要求本輪全矩陣合格 |

碰撞不能僅因機體未定型而被認定為純幾何問題。只有證據支持時才
歸因；原因未確定時記錄為估計／控制／模型共同作用或待辨識。

## 減少 sim-to-real 差距的方向

沿用實際PX4控制與估計接口、MAVLink語義及真實來源時間；模型的
質量、慣量、推力、滯後、幾何和相機外參由配置提供，明確區分估計
與實測。數值光流、初始坐標註冊和感測仿真不能被描述成已實測的
設備性能。實機接入時替換感測來源和標定資料，保留相同的資料合約
及任務控制接口。

M3C的115200 UART帶寬、~50 Hz HIGHRES_IMU與完整200 Hz IMU輸入之間的
缺口仍需如實說明；本輪不要求立即解決實機性能、刷機、參數寫入或
試飛。實機操作仍按使用者另外指示安排。

原有成功／失敗摘要、嚴格評分器、凍結配置和G1歷史證據保留原樣。
它們代表原研究條件下的結果，不能改寫成新的通過狀態；原高要求
測試集改為後續設計與可靠性研究，未跑完不再自動阻擋研發遷移。
