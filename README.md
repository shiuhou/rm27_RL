# RM27 Astra research sandbox

Independent research on **designated simulated competition fixtures** for a
150–249 g autonomous micro-UAV. No hardware commands or flight deployment.

Start with [Astra](astra/README.md), the [research journal](astra/docs/research_log.md)
and the [hardware evidence ledger](astra/docs/hardware.md).
The assembled prototype's next tests are specified in the
[real field experiment protocol](astra/docs/real_experiments.md).

The local `ardupilot/` and `rm_uav_lab/` directories remain separate reference
workspaces and are excluded from this repository's commits.
